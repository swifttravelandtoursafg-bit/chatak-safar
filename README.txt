# Chatak Safar — Website Package

This is a responsive, no-dependency website for Chatak Safar (چتک سفر) — Swift Travels and Tours.

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — mobile menu, year and inquiry email button
- `assets/banner.png` — supplied Chatak Safar banner
- `assets/logo.jpg` — supplied Chatak Safar logo

## Important: Google Sites
Google Sites does NOT directly upload an HTML website as a normal page. The easiest free workflow is:

1. Upload this folder to a free static host such as GitHub Pages, Netlify, or Cloudflare Pages.
2. Get the public website URL.
3. In Google Sites choose **Insert → Embed → By URL** and paste the public URL.
4. Publish your Google Site.

You can also use the content/design in this package to recreate the pages directly inside Google Sites.
